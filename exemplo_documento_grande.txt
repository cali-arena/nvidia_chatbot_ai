DOCUMENTO DE EXEMPLO PARA TESTE DO SISTEMA RAG
===============================================

Este é um documento de exemplo criado para testar o sistema RAG avançado com suporte a arquivos grandes.

SEÇÃO 1: INTRODUÇÃO AO SISTEMA RAG
==================================

O sistema RAG (Retrieval-Augmented Generation) implementado oferece capacidades avançadas para processamento de documentos grandes, com suporte até 2GB por arquivo. O sistema utiliza:

- ChromaDB como vector store principal
- Embeddings NVIDIA AI para alta qualidade
- Chunking inteligente com sobreposição
- Sistema de avaliação automática

SEÇÃO 2: ARQUITETURA TÉCNICA
============================

O sistema é composto por quatro componentes principais:

1. LargeFileProcessor: Processa arquivos grandes de forma eficiente
2. VectorStoreManager: Gerencia embeddings e vector store
3. RAGAgent: Agente inteligente para consultas RAG
4. RAGEvaluator: Sistema de avaliação de respostas

SEÇÃO 3: CONFIGURAÇÕES E PARÂMETROS
===================================

O sistema RAG pode ser configurado com os seguintes parâmetros:

- chunk_size: 1000 caracteres (padrão)
- chunk_overlap: 200 caracteres (padrão)
- max_file_size_gb: 2.0 GB (padrão)
- embedding_model: nvidia/Llama-3.2-3B-Instruct-TensorRT-LLM
- vector_store_type: chroma (padrão)
- retrieval_k: 5 documentos (padrão)
- similarity_threshold: 0.7 (padrão)

SEÇÃO 5: MÉTRICAS E AVALIAÇÃO
=============================

O sistema inclui um sistema de avaliação automática com as seguintes métricas:

1. Relevance Score: Relevância dos documentos encontrados (0-1)
2. Completeness Score: Completude da resposta (0-1)
3. Overall Score: Score geral de qualidade (0-1)
4. Confidence Score: Confiança na resposta (0-1)

SEÇÃO 8: LIMITAÇÕES E CONSIDERAÇÕES
===================================

LIMITAÇÕES ATUAIS:
- Tamanho máximo de arquivo: 2GB
- Processamento sequencial de arquivos
- Dependência de conexão com NVIDIA AI

CONSIDERAÇÕES TÉCNICAS:
- Memória RAM necessária para arquivos grandes
- Tempo de processamento proporcional ao tamanho
- Qualidade dos embeddings afeta resultados

SEÇÃO 9: TROUBLESHOOTING
========================

PROBLEMAS COMUNS:

1. RAG não funciona:
   - Verificar se dependências estão instaladas
   - Verificar logs no terminal
   - Procurar por erros de importação

2. Arquivo muito grande:
   - Verificar tamanho do arquivo (limite 2GB)
   - Dividir arquivo se necessário

3. Embeddings lentos:
   - NVIDIA embeddings são mais rápidos
   - Fallback para HuggingFace se necessário
   - Considerar cache de embeddings

4. Vector store não persiste:
   - ChromaDB salva em ./chroma_db/
   - Verificar permissões de escrita
   - Limpar cache se necessário
